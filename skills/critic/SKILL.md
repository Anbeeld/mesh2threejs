# Critic

Read the selected profile critic rubric. Accept only a valid packet containing exact oracle/candidate hashes, deterministic rows, beauty/alpha/semantic/depth/normal/material passes, comparison views, and turntable.

Inspect perspective proportions, fabrication/readability, identity features, and style coherence. Emit structured findings with criterion, evidence, severity, affected view/region, expected correction, and whether deterministic gates reopen. Do not edit candidate, oracle, or state.

Return PASS only if deterministic evidence passes and no visual finding remains. Same-context review is not independent; use the separate critic worker or mark certification degraded.

# Style contract

`low-poly-faithful` changes representation, not geometry authority. Macro dimensions, silhouette anchors, centers, orientation, articulation ownership, critical features, and repeated counts remain exact within the profile gate. Curves may use 6–16 intentional sides and microdetail may be omitted only when it is not marked critical.

The implementation combines oracle-envelope and feature-center anchors (mechanism B) with an analytical regular-polygon faceting corridor (mechanism C). Complexity caps are independent: fewer triangles never increase geometry tolerance. See `docs/style-gate-research.md` for the comparison and falsifiers.

Profiles may opt specific semantic IDs or `*` patterns into `featureSizePolicy`. Its positive minimum is expressed in object units; when the property is absent, no global physical feature-size threshold is invented.

# Generic build standard

1. Admit and register the oracle.
2. Establish primary bounds and orientation.
3. Match orthographic side/front/plan silhouettes and multi-axis sections.
4. Add attachments with explicit semantic ownership and zero unintended gap.
5. Preserve critical fittings; omit only style-authorized microdetail.
6. Verify depth/normal/semantic/material passes, complexity, board, turntable, and independent critic.

A matching single silhouette is insufficient. Bounds and views on all three axes must agree. Detached parts, mirrored forward orientation, wrong depth, and bad semantic grouping are critical failures.
